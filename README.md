# cloudtasks-equipo13

CloudTasks es una aplicación web que permite registrar y gestionar tareas, desarrollada como parte de un Laboratorio de la materia Seminario de Ingeniería de Software (Universidad ICESI).

## Funcionalidades

- Crear tarea con título, descripción, prioridad (baja/media/alta) y fecha límite.
- Listar tareas pendientes y completadas.
- Marcar tareas como completadas / revertir a pendientes.
- Eliminar tareas.
- Ordenar por prioridad o fecha límite.
- Resumen de progreso (porcentaje de tareas completadas).

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Supabase
- Vercel
- Cloudflare

## Etapas del proyecto

### Etapa 1: Desarrollo

Se creó la interfaz con HTML y CSS, se implementó la lógica con JavaScript y se gestionó el código mediante Git y GitHub.

### Etapa 2: Despliegue y base de datos

Se conectó la aplicación con Supabase para guardar las tareas y se publicó el proyecto en Vercel.

### Etapa 3: Acceso seguro

Se configuró Cloudflare para administrar el dominio, DNS y HTTPS de la aplicación.
